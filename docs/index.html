Developer & Submission Setup Guide

Run locally in 1 command or connect to live Twilio Sandbox.

1. Run Local Engine

# Install dependencies
pip install -r requirements.txt

# Run Flask server (Port 5000)
python app.py

2. Twilio Webhook Integration

# Expose local port 5000 with ngrok
ngrok http 5000

# Set Twilio Sandbox Webhook URL to:
https://your-ngrok-url.ngrok-free.app/bot
